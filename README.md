# qysystems.com.tr tanıtım sitesi

Tek sayfalık, iki dilli (Türkçe `index.html`, İngilizce `en/index.html`)
statik site. Derleme adımı, JavaScript, dış font ya da çerez yok; dosyalar
olduğu gibi yayına alınır.

- `style.css`: iki sayfanın ortak görünümü (açık ve koyu tema).
- `favicon.svg`: tarayıcı sekmesindeki simge.

Yerelde görmek için `index.html` dosyasını tarayıcıda açmak yeter.
