# qysystems.com.tr tanıtım sitesi

Tek sayfalık, iki dilli (Türkçe `index.html`, İngilizce `en/index.html`)
statik site. Derleme adımı, JavaScript, dış bağlantı ya da çerez yok;
dosyalar olduğu gibi yayına alınır.

- `style.css`: iki sayfanın ortak görünümü (teknik resim teması, yalnız açık renk).
- `fonts.css` ve `fonts/`: sitenin içinde duran yazı tipleri (Barlow ve
  IBM Plex Mono, SIL Open Font License; lisans metinleri klasörde).
- `favicon.svg`: tarayıcı sekmesindeki simge.

Yerelde görmek için `index.html` dosyasını tarayıcıda açmak yeter.
